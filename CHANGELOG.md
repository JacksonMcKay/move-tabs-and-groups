# Changelog

## 2.0.0 (2025-12-01)

### Breaking

- Existing shortcuts will be cleared because the underlying commands were
  renamed.
  - This was due to Chromium-based browsers sorting the keyboard shortcuts list
    based on the command name and I hadn't structured the names in such a way to
    enforce a nice ordering. This shouldn't happen again, sorry for any
    inconvenience to the whopping 38 users across the different browser stores.

### Added

- Shortcuts for moving a tab/group to the start/end of the tab bar
- Shortcut for creating a new tab in the current group
